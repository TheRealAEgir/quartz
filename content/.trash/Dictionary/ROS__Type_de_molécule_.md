# ROS (Type de molécule)

- Espèce réactive de l'oxygène (Reactive Oxygen Species en anglais)
- Les ROS sont un type de molécule obtenues dans un environnement acide. Ces cellules ont un fort pouvoir oxydatif, ce qui peut nuire à la survie des cellules. Certaines cellules immunitaires utilisent les ROS pour détruire leur cible
